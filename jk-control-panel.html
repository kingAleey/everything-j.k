HOW TO USE THE ADMIN PANEL

1. Add / edit products — fill the form, click Save Product.
2. Pictures — click the dashed box to upload; images are auto-compressed. You can also paste any image URL into the name field's place — no wait, use the upload box.
3. Price 0 — shows "Price on DM 💬" on the store. Perfect for preorders.
4. Save globally — product and settings changes are saved to the shared Supabase database and appear on the live store for everyone. No data.js replacement is required.
5. Checkout — customers' carts redirect to your Instagram DM with the order summary copied. 💌
