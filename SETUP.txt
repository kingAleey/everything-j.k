This package was rebuilt from the original working project and then the requested UI changes were added.

1) SUPABASE DATABASE
Open Supabase > SQL Editor and run ALL of supabase.sql.
This migration is safe for an existing database: it adds missing columns (including sort_order) instead of recreating the tables, and it does not overwrite existing products/settings.
At the end it returns product/settings verification rows.

2) ADMIN USER
Create your admin account in Supabase > Authentication > Users.
Then run this with your exact admin email:

UPDATE auth.users
SET raw_app_meta_data =
  coalesce(raw_app_meta_data, '{}'::jsonb) || '{"role":"admin"}'::jsonb
WHERE email = 'YOUR-ADMIN-EMAIL';

Log out and sign in again after changing the role.

4) NETLIFY
Upload the contents of this folder to GitHub and let Netlify deploy from that repository.
Do not upload any secret/service-role Supabase key. The browser uses only the publishable key.

5) GLOBAL UPDATES
Products and store settings are saved to Supabase, not localStorage. Product images/logo uploads use the jk-assets storage bucket.

6) PRODUCT CROP
The admin image upload opens a 10:11 crop editor matching the homepage product card ratio. Drag/zoom, then choose the crop.

7) LOGO
Store Settings includes homepage logo upload and animation choices: fade, glow, float, slide.

8) SAFETY
Do not delete your existing Supabase tables or users. If you already ran an older SQL version, run this safe migration instead.
