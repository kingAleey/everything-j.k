EVERYTHING J&K — SUPABASE SETUP

You do NOT need to rebuild the website.

1. In Supabase, open SQL Editor -> New query.
2. Open the file supabase.sql from this folder.
3. Copy everything in supabase.sql into the SQL Editor.
4. Click Run.
5. Go to Authentication -> Users.
6. Create the ONE admin user you will use for the admin dashboard (email + password).
7. If your Supabase project allows public sign-ups, turn public sign-ups OFF after creating the admin user. Only the admin user should be able to write products/settings.
8. Keep the publishable key in supabase-client.js. It is intended for browser use. NEVER put an sb_secret key or service-role key in this project.
9. Upload/push the entire folder to GitHub and let Netlify redeploy it.
10. Open /admin.html on the live Netlify site and sign in using the Supabase Auth email/password you created.
11. Add/edit a product and click Save Product. It should now update Supabase and therefore the public website for everyone.

IMPORTANT:
- The existing products are seeded by supabase.sql, so you do not need to re-enter them.
- The existing localStorage catalogue is kept only as an offline fallback. The live site reads Supabase first.
- Product images already in the project continue using the assets/ paths. Newly uploaded admin images are currently stored as compressed data URLs in the database. For a larger catalogue, move images to Supabase Storage later.
- The publishable key is safe to expose in frontend code when RLS is configured, but secret/service-role keys are NOT safe to expose.
